# 根本就没有这样的象棋 1.7.4

- 黑方改为己方在下方的视角，棋子文字保持正向；换边时视角与可走的一方同步。
- 优化随机匹配建连：双方支持时增量交换连接地址，不再顺序等待完整收集；同时准备加密中继，直连优先。
- 改善非主持端走棋体验：主持端先发棋局再刷新自己，缓存重复的走法和将军计算，减少界面重绘。
- 同意开启新棋局后交换红黑；重新建立连接也记住下一次颜色偏好，提供连接的一方不再总执红。

保留悔棋/新棋局双方申请、拒绝后原局继续，以及名称和输入框焦点修复。双方均升级到1.7.4使用本次完整优化；1.7.2/1.7.3可从应用内检查更新，1.7.1及更早版本需手动覆盖安装一次。

安装包约174KB，沿用原包名和签名。57项相关回归通过；本机模拟缓慢地址收集时，增量建连约0.6–1.4秒，非手机公网性能承诺。实体手机性能、系统软键盘、安装/升级、后台和跨运营商连接尚未实测。
