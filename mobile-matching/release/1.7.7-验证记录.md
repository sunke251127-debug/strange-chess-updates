# 1.7.7：单机每手256次搜索

将手机版单机对战的每手新增MCTS模拟数由1024改为256。搜索核心常量统一用于后台任务校验、前端进度和落子检查、安装包元数据及发布预检；导出工具的部署默认值同步改为256。

继续部署同一份历史第50轮FP32模型。ONNX文件SHA256保持为`680e53bea21510610a7097e3ded75257d9b028d9fa69b2c6d7a74d6fdd557e93`；模型来源、参数、搜索深度和推理批量保持原配置。

针对性检查覆盖：

- 7项搜索单测：新增访问严格为256、复用后累计512、吃明将、异常清理、公开信息隔离、长局面及训练规则一致性。
- 3项真实模型/浏览器检查：PyTorch与WASM数值对照、原生存档桥接、红黑落子、进度上限256、悔棋、切换取消和继续棋局。
- 1项PWA缓存与更新生命周期回归。
- 7项签名APK/更新清单检查：实际APK ZIP资源、原签名、包内真实模型256次搜索、前端上限256、本地双人、双方WebRTC和发布清单一致性。

检查在本机浏览器和JVM中执行，包内模型检查阻断外部网络请求。没有实体手机或模拟器，手机实际耗时与系统安装升级没有实测。

详细安装包身份与检查结果见`offline-verification.json`。1.7.6的完整训练模型及历史验证记录继续保留。
