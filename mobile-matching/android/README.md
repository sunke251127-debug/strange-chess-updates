## 1.7.7 单机对战

每手搜索由上一版的1024次降低为256次，搜索预算为原来的四分之一。

顶部点“单机对战”，选择红黑阵营后开始。固定使用上一轮已完成训练的第50轮快照，完整模型保存在APK里；手机本地每手完成256次搜索后落子，不需要电脑、服务器或下载模型。思考进度可见，悔棋和新局会取消旧搜索。

单机存档与本地双人分开，额外写入应用私有存储，重启后可以继续。单机采用模型对应的将军8次、重复局面3次限制；联机和本地双人规则不变。系统WebView需要支持WebAssembly与SIMD，模型加载报错时可更新系统WebView后重试。

## 1.7.5 已有功能

- 联机功能单独从顶部“联机对战”进入，与设置分开。

## 保留的联机优化

- 黑方以己方在下方显示，文字保持正向，换边后视角跟着调整。
- 随机匹配增量交换连接地址，同时准备中继，减少顺序等待。
- 主持端先给对方发棋局，再刷新本地；缓存重复规则计算，改善非主持端交互。
- 同意新局后双方轮换红黑；重新连接也记住下一次颜色偏好，主持端不固定为红方。

## 安装和升级

1. 1.7.2至1.7.5用户在应用内“检查更新”，下载后确认系统安装提示即可升级。1.7.1及更早版本需先手动下载并覆盖安装一次，无需卸载或清除数据。
2. 桌面名称是“这样的象棋”，游戏内标题为“根本就没有这样的象棋”，均去掉“匹配版”后缀。
3. 联机双方都升级到1.7.5，使用新的悔棋和新棋局申请流程；拒绝申请会保留原局面。
4. 目标为安卓8.0+和兼容安卓APK的鸿蒙4.2，不适用于鸿蒙NEXT。具体机型仍需实测。

默认更新源：https://github.com/sunke251127-debug/strange-chess-updates 。更新器继续校验更高版本、大小、SHA256、包名和原发布者证书；安装由系统弹窗确认。
