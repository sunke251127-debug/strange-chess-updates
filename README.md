## 玩法介绍

这是“先按点位走，翻面才见真身”的暗棋象棋，采用暗子翻面与以下特殊规则。

### 开局与翻面

1. 使用9×10棋盘，32枚真实棋子红黑各16枚、各有一枚将/帅，全部混洗后放在标准初始点位，背面朝上。
2. 红方先走，之后双方每走一手固定换边。先点棋子，再点高亮的合法落点。
3. 暗棋首次按它所在初始点位的阵营和棋种行动，落子后翻面；从此按真实颜色归属和真实棋种走法行动。
4. 你走出的暗棋可能翻成对方的棋子。例如红方从暗车点位走一步，翻出黑马后，这枚棋子归黑方，后续按马走；本步结束仍轮到黑方。

### 棋子怎么走

下表适用于翻面后的真实棋种；暗棋首次仍按初始点位走法。

| 棋子 | 本版走法 |
|---|---|
| 车 | 沿横线或竖线走任意格，中间不能有子。 |
| 马 | 走“日”字，有“蹩马腿”限制。 |
| 象 / 相 | 走“田”字，有“塞象眼”限制，可以过河。 |
| 士 / 仕 | 斜走一格。暗士点位首次只可在己方九宫内斜走；翻明的士可全盘斜走。 |
| 将 / 帅 | 横竖走一格，可以离开九宫、过河；允许将帅照面，不采用飞将吃将。 |
| 炮 | 不吃子时沿横竖线走，中间不能有子；吃子时必须隔恰好一个棋子。 |
| 兵 / 卒 | 向本方前进方向走一格；过河后也可左右走一格，不能后退。 |

不能吃掉当前公开归属为己方的棋子。将军只作提示，不强制应将，也不禁止送将。

### 暗将保护与胜负

- 尝试吃未翻面的真实将/帅时，攻击棋子留在原位，将/帅原地亮出，本次不吃子、不直接判胜；这仍算一手并换边。
- 已经翻明的将/帅可以正常被吃，吃掉对方明将/帅即可获胜。
- 一方没有合法走法时判负。

### 本地双人与联机

- **本地双人**：一台手机轮流操作红黑双方，可用底部“悔棋”和“新棋局”。
- **随机联机**：双方打开顶部“联机对战”，点击“随机联机”等待配对；网络受限时会尝试加密中继。
- **好友直连**：一方点“邀请好友直连”并发送邀请；另一方粘贴邀请点“加入 / 连接”，再把生成的回复码发回；邀请方粘贴回复码并点“加入 / 连接”。
- 联机双方分别以己方在下方显示，棋子文字保持正向。
- 联机悔棋撤销双方最近的一手，开启新局则重新洗牌；两种操作都需对方明确同意，拒绝就保留当前棋局继续下。
- 同意新局后双方交换红黑，新的红方先走；悔棋或断线重连不会额外换色。继续落子、掉线或离开会使未处理的申请失效。
- 更新从左下角“设置 → 更新 → 检查更新”进入，下载后按系统提示确认安装。
